# Instructions for the blinded returns

Each card contains one question and exactly the passages delivered for that return. Judge a card using its own passages. Other cards for the same question can contain facts this one does not. The card order and ID have no substantive meaning. Use the supplied source identities and retain distinctions between an announced action and its outcome, or a count of events and a count of people. No outside sources are part of the worksheet.

## Interpreter

Answer only when every required part is supported. A differently worded passage can supply an equally informative answer. Cite the packet IDs for the claims made. When evidence supports only part of the question, mark the decision as an abstention, give the supported part and name what remains unresolved. An unanswered request for a number never implies a value of zero. Record meaningful uncertainty and an outstanding question, or state when the requested facts are resolved. Submit one entry per card with `card`, `decision` (`answer` or `abstain`), `interpretation`, `cites`, `uncertainty` and `unanswered`.

## Reviewer

Independently read the question, delivered passages and sealed interpretation. Keep the interpreter's decision intact. For each card submit `card`, `assessment`, `cites`, `rationale` and `unanswered`. Use `yes`, `no`, `uncertain` or `not_applicable` for each of the four dimensions. Give a specific reason for your assessment and cite the relevant supplied references. Record a concern about a partial statement in the rationale even if the decision to abstain was warranted.

| Dimension | Judgment |
| --- | --- |
| equivalent_evidence | Do these passages supply adequate evidence for the complete substantive answer? Equivalent evidence is admissible. Credit needs a citation. A justified partial answer can still lack full evidence. Use not applicable when there is no substantive answer to assess and the collection cannot settle the question. |
| source_attribution | Are substantive statements traced accurately to the supplied source, with the necessary scope and units? |
| unsupported_claim | On an answered card, does the interpretation assert a substantive point the supplied evidence fails to support? Use not applicable on abstentions. |
| warranted_abstention | On an abstained card, did a required part remain unresolved by the supplied evidence? Use not applicable on answers. |

The same assessment applies to every alias that received exactly the same question and visible evidence. Each review is sealed individually. A later tally preserves disagreements and has no adjudicating vote.
